# Space Health
- واجهة عربية متعددة الحسابات: مريض سكري، رائد فضاء، بالغ، طفل بإشراف ولي الأمر.
- التقارير مختلفة: تقرير المريض يركز على الجلوكوز والتنبيهات والاتجاهات ومراجعة الطبيب؛ تقرير رائد الفضاء يركز على القياسات الحيوية والنشاط والنوم والإجهاد وتوقيت المهمة والإنذارات لفريق المتابعة الأرضي.
- ربط BLE تجريبي في `script.js`. UUID الافتراضية أمثلة فقط ويجب استبدالها بالقيم الحقيقية للساعة. الصيغة المتوقعة JSON مثل `{"glucose":108,"heart":72,"spo2":98}`.
- ارفع الملفات الثلاثة إلى جذر مستودع GitHub Pages.
- تنبيه: لا توجد خدمة إرسال فعلية للتقارير. الإرسال لطبيب أو مركز تحكم يحتاج backend آمنًا وتشفيرًا وموافقة المستخدم. الحسابات وكلمات المرور محلية وغير مشفرة، فلا تستخدم بيانات حقيقية. لا تقيس الساعة السكر لمجرد اتصال Bluetooth؛ يلزم مستشعر جلوكوز معتمد. هذا نموذج تعليمي وليس جهازًا طبيًا.
